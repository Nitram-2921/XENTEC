## 💡 Sobre el proyecto

**XENTEC** es un proyecto de desarrollo web dinámico realizado en colaboración con **Benjamín Suárez**.

El objetivo es construir una experiencia web que permita presentar contenido mediante una interfaz visual e interactiva, poniendo en práctica conocimientos de programación y diseño web.

Este proyecto representa una experiencia de desarrollo colaborativo, donde trabajamos en la construcción de una propuesta digital y en la aplicación de diferentes conceptos del desarrollo web.

## ✨ Características del proyecto

- **Desarrollo web dinámico:** creación de una experiencia web interactiva.
- **Diseño de interfaz:** organización visual y presentación del contenido.
- **Programación web:** aplicación de conocimientos de desarrollo frontend.
- **Trabajo colaborativo:** proyecto realizado en conjunto.
